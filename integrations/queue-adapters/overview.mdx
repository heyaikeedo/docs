## Overview

Aikeedo runs slow work, such as imports and connector refreshes, as background jobs. By default the jobs wait in your database, which needs nothing extra. The Queue Adapters plugin lets them wait in a dedicated queue service instead, which takes that load off the database on busy sites.

<Note>
  The Queue Adapters plugin is available for purchase from the [Aikeedo Marketplace](https://aikeedo.com/marketplace/?utm_source=docs&utm_medium=content). It needs Aikeedo 5.2 or later.
</Note>

## Choosing an adapter

1. Go to **Settings → System → Queue adapters** and open the adapter.
2. Fill in the connection, turn on **Status** and press **Save changes**. With **Status** on, saving tests the connection first: if the service refuses it, an error message says why and nothing is saved.
3. Go to **Settings → System → Queue**, press **Change** next to **Adapter** and choose it. Running workers restart on their own.

<Warning>
  Switching adapters does not move jobs that are already waiting. Let the queue empty first: the Queue page shows how many jobs are waiting.
</Warning>

Cron is enough with any adapter: each cron run works the queue when no worker is running. A worker kept running with Supervisor or systemd picks jobs up sooner. See [Background Jobs & Queue](/advanced/queue).
