Aikeedo uses Luma AI's Agents API for video in **Video** and images in **Imagine**. Results are read back by a scheduled task, so Luma needs no callback to your site.

## Models

| Model | Type | Replaces |
| --- | --- | --- |
| **Ray 3.2** | Video | Ray 2, Ray Flash 2 and Ray 1.6 |
| **Uni-1** | Image | Photon Flash 1 |
| **Uni-1 Max** | Image | Photon 1 |

You can also add other Luma image and video models yourself on the [Models](/advanced/models#add-a-model) page.

## Connect Luma AI

<Steps>
  <Step title="Create an API key">
    Sign in to the [Luma developer platform](https://platform.lumalabs.ai/) and create an API key. These keys start with `luma-api-`.
  </Step>
  <Step title="Enter the key in Aikeedo">
    Go to **Settings → Luma AI**, paste the key into **API Key** and click **Save changes**.
  </Step>
  <Step title="Switch the models on">
    Go to **Settings → Models**, filter by the **Luma AI** provider, check the prices and switch on the models you want to offer.
  </Step>
  <Step title="Check cron">
    Make sure the [cron job](/setup/initial-setup#setting-up-the-cron-job) runs every minute. Luma results are only picked up by it.
  </Step>
</Steps>

## How results come back

Luma's Agents API doesn't send results to your site. Instead, the **Read the results of Luma generations** scheduled task checks unfinished generations every minute and saves the results.

- **Images** wait in the request for up to 45 seconds. Any that aren't finished by then are picked up by the scheduled task.
- **Videos** are always picked up by the scheduled task.
- **Input images** are sent to Luma inline, so Luma doesn't need to reach your site, and local installations work too.

<Warning>
  Without cron, Luma generations never finish. The dashboard's **System health** card warns when the cron job isn't set up or has stopped.
</Warning>

## Pricing

The catalog lists Luma's costs, at Luma's $0.003 per Luma credit:

| Model | Cost |
| --- | --- |
| Ray 3.2, 5 seconds | \$0.06 (360p), \$0.15 (540p), \$0.30 (720p), \$1.20 (1080p) |
| Ray 3.2, 10 seconds | \$0.18 (360p), \$0.45 (540p), \$0.90 (720p), \$3.60 (1080p) |
| Uni-1 | \$0.042 per output image (2K), plus \$0.003 per input image |
| Uni-1 Max | \$0.102 per output image, plus \$0.003 per input image |

These are your costs. Users pay cost × markup × credits per USD, set on the [Credit Pricing](/billing/credit-pricing) page.

## Upgrading from 5.2

Aikeedo 5.3 moves from Luma's retired Dream Machine API to the Agents API:

- Enter a key from [platform.lumalabs.ai](https://platform.lumalabs.ai/) under **Settings → Luma AI**. These keys start with `luma-api-`.
- Ray 2, Ray Flash 2, Photon 1 and Photon Flash 1 are switched off. Switch on Ray 3.2, Uni-1 and Uni-1 Max: they arrive switched off.
- The Luma webhook address, `/webhooks/luma/{id}`, is removed. Nothing needs to reach your site any more.
