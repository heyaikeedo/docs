## Introduction

Aikeedo has keyboard shortcuts for the actions people use most: starting something new, searching, moving around, and managing items. Shortcuts appear where they apply, as small key hints beside buttons and in menus, and a cheat sheet lists all of them.

There is nothing for you to configure. Each user can switch shortcuts off for themselves.

<Note>
  `Ctrl` is shown as `⌘` on Mac. The keys on screen always match the keyboard the user is using.
</Note>

## Shortcuts

### General

| Shortcut | Action |
| --- | --- |
| `Ctrl + Shift + O` | **New**: start a new chat, or a new item in the current tool |
| `N` | **Create** on the current page |
| `Ctrl + K` | **Search** |
| `Ctrl + Shift + X` | Turn [Private mode](/advanced/private-mode) on or off |
| `Ctrl + /` | Open the keyboard shortcuts cheat sheet |

### Navigation

| Shortcut | Action |
| --- | --- |
| `Ctrl + Shift + S` | Show or hide the sidebar |
| `Ctrl + Shift + D` | Show or hide the details panel |
| `Ctrl + Shift + ,` | Open settings |

### Item menu

These work only while a row's **…** menu is open, for example a conversation in Recents. Each key is the first letter of the action.

| Key | Action |
| --- | --- |
| `U` | Mark as read or unread |
| `S` | Share |
| `R` | Rename |
| `D` | Delete |
| `O` | Open in a new tab |

### Composer

These are listed in the cheat sheet so they are easy to find. They always work and cannot be switched off.

| Key | Action |
| --- | --- |
| `Enter` | Send message |
| `Shift + Enter` | New line |
| `Esc` | Close a dialog or menu |

## Where users find them

- **On the interface.** Hover over a button, or open an item's menu, to see its shortcut.
- **The cheat sheet.** Press `Ctrl + /`, or choose **Keyboard shortcuts** in the account menu.
- **Settings → Shortcuts.** The full list, grouped, with a switch for each one.

## Switching shortcuts off

Some shortcuts can clash with a browser extension or a screen reader. Users can switch off any of them under **Settings → Shortcuts**, and use **Restore defaults** to go back. The choice is saved to the user's account, so it follows them across browsers.
