This guide outlines the necessary components and configurations to ensure your server is ready to host Aikeedo efficiently.

## Core Requirements

### PHP and MySQL Versions

Aikeedo requires up-to-date versions of PHP and MySQL to ensure optimal performance and security:

<CardGroup cols={2}>
  <Card title="PHP Version" icon="brand-php">
    8.2 or later. 8.5 recommended
  </Card>
  <Card title="MySQL Version" icon="database">
    8.0 or later
  </Card>
</CardGroup>

<Note>
  Using the latest stable versions is recommended for the best experience and to take advantage of the newest features and security updates.
</Note>

### PHP version policy

Aikeedo 5.3 runs on PHP 8.2 to 8.5 and is tested up to PHP 8.5, which we recommend. **Aikeedo 6 will need PHP 8.4 or newer**, with 8.5 recommended.

Each PHP version gets security fixes for a limited time. These dates come from [php.net](https://www.php.net/supported-versions.php):

| PHP version | Security fixes until |
| --- | --- |
| 8.1 | December 31, 2025 |
| 8.2 | December 31, 2026 |
| 8.3 | December 31, 2027 |
| 8.4 | December 31, 2028 |
| 8.5 | December 31, 2029 |

Aikeedo checks the PHP version your site and your cron job run on. The admin dashboard and the **Status** page show:

- **Upgrade PHP** when the version is no longer supported.
- **Plan a PHP upgrade** when the version is older than 8.4, or within 90 days of the end of its security fixes.
- **Newer PHP than tested** when the version is newer than the one Aikeedo is tested with.
- **Cron runs a different PHP** when the cron job uses a different PHP version from your site.

See [System Health](/setup/system-health) for the other checks.

#### Upgrading PHP

1. Check that your PHP extensions are installed for the new version too.
2. Switch the PHP version for your site in your hosting control panel, or install the new version on your server.
3. Point your [cron job](/setup/initial-setup#setting-up-the-cron-job) at the same PHP binary.
4. Open the admin **Status** page and check the PHP version for the site and for cron.

Most hosting control panels let you change the PHP version per site. On a VPS, your distribution's packages or a PHP repository provide newer versions.

<Tip>
  Need help? See [Aikeedo support](https://aikeedo.com/support/?utm_source=docs&utm_medium=content) for setup and upgrade help.
</Tip>

### Essential PHP Extensions

To run Aikeedo smoothly, make sure your PHP installation includes these extensions:

<Accordion title="Click to view required PHP extensions">
  - bcmath
  - ctype
  - curl
  - dom
  - fileinfo
  - gd
  - intl
  - json
  - libxml
  - mbstring
  - openssl
  - pcre
  - phar
  - simplexml
  - tokenizer
  - xml
  - xmlwriter
  - zip
</Accordion>

<Tip>
  Most of these extensions are typically included in standard PHP installations. If you're unsure, consult your hosting provider or server administrator.
</Tip>

If you run a [background worker](/advanced/queue#running-a-background-worker), the `pcntl` extension is recommended. It lets the worker stop a job that runs past its time limit and shut down cleanly when restarted. Cron works without it.

### Hosting Recommendations

While Aikeedo can run on various hosting environments, we strongly recommend using a Virtual Private Server (VPS) for better control and performance, especially for commercial use cases.

<Tip>
  Start with a smaller VPS configuration and resize as needed. This approach allows you to scale your resources based on your actual usage and growth.
</Tip>

Popular VPS providers that work well with Aikeedo include:

- DigitalOcean (via our [referral link](https://m.do.co/c/084136521a6a))
- Vultr (via our [referral link](https://www.vultr.com/?ref=9690154))
- Amazon Web Services ([AWS](https://aws.amazon.com/))

<Note>
  While most shared hosting environments are supported, they may have limitations that could affect Aikeedo's performance. For the best experience, especially for commercial use, we strongly advise using a VPS.
</Note>

<Warning>
  Special note about Cloudways: The text streaming function doesn't work on Cloudways servers due to their complicated server stack. Unfortunately, they don't provide root access to the server to modify the configuration. This issue cannot be resolved at the application level as it's not application-related. If text streaming is crucial for your use case, we recommend choosing a different hosting provider.
</Warning>

## PHP Configuration

Proper PHP configuration is crucial for Aikeedo to function correctly. Adjust the following settings in your `php.ini` file:

- **File Uploads:** On
- **Post Max Size:** 25MB or more
- **Upload Max Filesize:** 25MB or more

<Note>
  If you're not familiar with editing the `php.ini` file, don't worry! Many hosting control panels provide user-friendly interfaces to adjust these settings. If you need help, check out the [PHP configuration guide](https://www.php.net/manual/en/configuration.file.php) or contact your hosting provider.
</Note>
